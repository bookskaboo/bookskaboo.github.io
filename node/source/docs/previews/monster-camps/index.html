Monster camp resource rework

For new worlds, keep each camp’s reward visible as a persistent resource deposit. Fully suppress the camp to connect a Production node and extract it. Replace the settlement Tribute lifecycle with an access gate on the deposit. Existing worlds retain their current Tribute behavior.

Requested and settled

  • World compatibility: apply the rework only to newly created worlds. Existing worlds keep their current camp behavior, including when loading a save or exploring previously unvisited maps. Do not convert Tribute stock, rewire routes, or migrate existing worlds to guarded deposits. Confirmed during this review.
  • Show the guarded deposit whenever its map is visible, including before the first suppression check. Do not reveal unexplored maps.
  • Allow extraction only after a successful check has brought camp strength to its existing 10% minimum. A fresh 25% camp still needs two passes: 25 → 15 → 10.
  • Locked interaction: allow inspection and show the exact blocking reason; reject new extraction connections and resource withdrawals until full suppression. Apply the same gate to every collection route. Preserve previously established connections when suppression later lapses. Confirmed during this review.
  • Dwarven Camps, Villages, and Kingdoms guard Mythril.
  • Dwarven placement: add a guarded Mythril deposit while preserving ordinary Iron, Copper, Stone, and Forest. Confirmed during this review.
  • Goblins guard one fixed Iron, Stone, or Copper deposit, chosen when generating the map. Use the matching ordinary deposit slot, so it replaces that map’s normal deposit of the same material. Keep the other ordinary deposits and Forest.
  • Retain current camp rates as base regeneration: Goblin 6 / 18 / 36 and Dwarven 1 / 5 / 12 items per five seconds for Camp / Village / Kingdom. Confirmed during this review.
  • Use the same maximum reserve as other ordinary deposits on that map. Reuse the shared map-cap function, including its existing mod multiplier and tier ceiling. Default maximum: 1,000 + 500 × map tier, capped at tier 10.
  • Initial stock: start at the full ordinary map reserve, visible but inaccessible until the camp is fully suppressed. For example, a tier-4 deposit starts with 3,000 items under default rules. Confirmed during this review.
  • Suppression lost: relock extraction and pause regeneration. Preserve the reserve, attached Extractor, and cables. Existing machines resume once suppression is restored; no rebuilding or reward-node respawn. Confirmed during this review.
  • Upgrade formula: use all existing mineral-regeneration multipliers on the camp base rate: ×2 after Mineral Regeneration 2, ×(1 + 0.2 × Mineral Regeneration Rate completions), and ×(1 + endgame Resource Regeneration completions). Mineral Regeneration itself remains optional for guarded deposits and adds no separate regeneration stream. Preserve fractional output over time; pause at the cap and discard overflow. Confirmed during this review.
  • Depletion: retain the empty deposit and its connections. Let camp regeneration refill it while fully suppressed, without requiring Mineral Regeneration research. Never turn it into a Deep Hole. Confirmed during this review.
  • Mythril progression: unlock Mythril Refining on the first actual Mythril extraction from a guarded Dwarven deposit. Visibility, full suppression, and reserve regeneration alone do not trigger the unlock. Once earned, retain the unlock through saves and reloads. Existing worlds retain their current unlock behavior. Confirmed during this review.
  • Relocation: move the camp and its linked guarded deposit together through the existing Monster Camp Relocation upgrade. Prevent independent resource relocation from separating the pair or bypassing suppression. Confirmed during this review.
  • Corner output titles become α Piece, β Piece, γ Piece, and δ Piece, using current item names. Keep encounter names, objectives, reward amounts, output capacity, and serialized IDs.
  • Review using this interactive local prototype before committing to game implementation.

Implementation scope

All design decisions in this review are settled. Implement the new-world behavior only after the user requests implementation. The local test page is an isolated demonstration; the game has not been changed or committed by this review.

World rules version

Store the selected camp rules with each newly created world. A saved world without the new rules marker uses the existing Tribute system. Loading, importing, saving again, or exploring a new map must preserve that world’s rules. Worlds created with guarded deposits continue to use them after reload.

Existing worlds

Keep their camp progress, stored and in-flight items, collection routes, earned unlocks, and current regeneration and relocation rules. No Tribute conversion or resource replacement is required in those worlds.

Implementation checks after agreement

Verify fresh map generation, fixed Goblin selection after reload, map caps, both successful checks, failure and recovery, empty deposits, full-cap behavior, locked transfers and alternate extraction routes, Mythril progression, camp relocation, and repeated save loading. Cover all settlement sizes and all four corner rewards. Verify that new worlds retain guarded-deposit rules after save and reload, and that existing worlds retain Tribute behavior after loading, importing, saving, and exploring new maps. Inspect normal and narrow screens, run workspace tests and the site build, then conduct a separate normal-gameplay balance run.

Prototype limits

This page demonstrates the agreed states and rates in isolation. It has no camp AI, automated extraction timing, obstruction collision, mod support, offline simulation, research progression, or world-version persistence. Simulated check and time controls are review tools. They are not evidence of a completed gameplay or balance test.
