# Research catalog

[System index](../README.md)

Generated base-game reference. Run `npm run docs:systems` after catalog changes; do not edit this file by hand. Mods and existing save state can change runtime values.

Sources: [research](../../../src/content/research.ts), [researchGuidance](../../../src/content/researchGuidance.ts), [coreResearch](../../../src/content/coreResearch.ts), [machineEfficiency](../../../src/content/machineEfficiency.ts), [endgame](../../../src/content/endgame.ts).

130 live unmodded projects, including character upgrades, automatic discoveries and repeatables. Costs are the assembled first-purchase prices after minimum-price rules. Extra Map Point awards a banked point; its row is the opening price and repeatable costs can grow. Prerequisites include both prerequisite fields; an internal production milestone has no research card. Applied-mod factories retain their existing catalog pending Upgrades support.

## Progression review chart

All live projects in Core-stage order, with prerequisites before dependent projects using the game's research tree. Independent branches within a stage have no mandatory order; ties retain catalog order. A stage includes any later Core access required by prerequisites or a Core-production trigger. Automatic discoveries can occur at different times during play.

**Highest Core** is the highest-tier Core in the project's bill. **Number cost** is the quantity of that Core on the first purchase, not the total bill. All current paid opening bills require the same quantity of every lower Core too. Simple Core is a starting Refiner recipe with no research gate or research row. Automatic discoveries cost 0. Repeatables are marked ↻; later prices can grow. Extra Map Point shows its opening point-purchase price. Unmodded new, loaded and replaced factories bank points; later bills depend on completion count and Core access, and existing quoted bills retain their amounts and paid contributions through conversion. Spending one saved point activates a frontier, with travel separate. Destination-priced quotes remain a compatibility path for applied-mod factories whose saved rules select it. See [Research](../research.md#payment-cycles-and-map-points) and [map rules](../map-nodes-and-exploration.md) for current pricing and compatibility. Author-only survey/tab proposals are outside this live catalog.
