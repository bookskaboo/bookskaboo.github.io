# Bot assembly catalog

[System index](../README.md)

Generated base-game reference. Run `npm run docs:systems` after catalog changes; do not edit this file by hand. Mods and existing save state can change runtime values.

Sources: [botAssembly](../../../src/content/botAssembly.ts), [recipes](../../../src/content/recipes.ts).

A Bot Plant automatically combines one frame and one gun. AP is frame strength × gun multiplier. Assembly time and research gate use the higher part tier. Equal AP results share a stock bucket; a serialized bot ID does not preserve the exact parts used to build it.
