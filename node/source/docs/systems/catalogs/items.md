# Materials and resource use catalog

[System index](../README.md)

Generated base-game reference. Run `npm run docs:systems` after catalog changes; do not edit this file by hand. Mods and existing save state can change runtime values.

Sources: [items](../../../src/content/items.ts), [recipes](../../../src/content/recipes.ts), [botAssembly](../../../src/content/botAssembly.ts).

Every material name and serialized ID is listed, including compatibility-only bot buckets and deferred Power. Recipe consumers below are direct inputs; recursive raw-resource bills also depend on recipe alternatives, waste recovery and acquisition support. Non-recipe sinks are covered in [resource use](../resource-use.md). Suppression Bot variants share one logistics material while retaining AP in stock.
