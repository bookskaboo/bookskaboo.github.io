Generated base-game reference. Run `npm run docs:systems` after catalog changes; do not edit this file by hand. Mods and existing save state can change runtime values.

Static socket families are templates. Recipe selection, Road direction, tribute material and defeated Golems change effective sockets. Capacity columns show capability defaults; runtime variants are explained in the relevant system document.
